# PROJECT RULES – EXERCISE 1

## 1. Technology Stack

- React 19
- Vite
- JavaScript ES6+
- JSX
- CSS Modules

## 2. React Standards

- Use functional components only.
- Use ES6 default parameters instead of defaultProps.
- Use const by default.
- Use immutable data handling.
- Use stable keys when rendering lists.
- Do not use deprecated React APIs.

## 3. Semantic HTML

- Zero div elements inside DeveloperCard.jsx.
- Prefer article, header, hgroup, dl, dt, dd, ul, li and Fragment.
- Maintain a logical heading hierarchy.

## 4. Accessibility

- Use appropriate ARIA attributes.
- Provide meaningful image alt text.
- Ensure semantic structure supports screen readers.

## 5. Styling

- Use CSS Modules.
- Use CSS Custom Properties.
- No inline styles.
- Support 375px responsive viewport.
- Prevent horizontal overflow.

## 6. Security & Reliability

- Use HTTPS for external image resources.
- Define explicit image dimensions.
- Implement avatar fallback initials.
- Never use dangerouslySetInnerHTML.

## 7. AI-Assisted Development

- Follow TASK_DECOMPOSITION.md.
- Implement one atomic task at a time.
- Verify generated code before integration.
- Do not generate the entire exercise in one prompt.
- Keep Git commits small and meaningful.
