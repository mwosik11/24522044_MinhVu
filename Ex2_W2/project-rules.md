# Exercise 2 — Project Rules

## Coding Rules
- Use const and let; never use var.
- Use ES modules with import/export.
- Do not use raw innerHTML for rendering.
- Do not use inline HTML event handlers.
- Use semantic HTML elements.
- Keep state management separate from UI rendering.

## Workflow Rules
- Implement one task at a time.
- Define expected behavior before implementation.
- Test each task before marking it complete.
- Use atomic Git commits.
- Do not claim a test passed until it has been run.
